## 1. Komponen saya
Komponen yang saya kelola berfokus pada ekstraksi awal, profil kualitas data, serta tahap pembersihan awal dataset Kasus 10 (Kesetaraan Gender). Komponen ini berperan penting sebagai pondasi pipeline kelompok untuk memastikan validitas struktur kolom, konsistensi tipe data, dan integritas skema sebelum data diproses lebih lanjut oleh anggota tim lain pada tahap agregasi dan transformasi.

## 2. Keputusan wrangling
Keputusan utama yang diambil adalah menerapkan filter validasi skema dan pemeriksaan SHA-256 pada saat pengunduhan data mentah, serta menolak metode improvisasi manual tanpa skrip terotomatisasi. Alternatif mengunduh file secara manual atau mengabaikan pencocokan *checksum* ditolak karena berisiko memasukkan data yang korup atau tidak konsisten dengan spesifikasi kasus 10. Dampak dari keputusan ini adalah terjaminnya 100% integritas file mentah yang diunduh sehingga tidak ada baris valid yang terbuang akibat pembacaan file yang rusak.

## 3. Kegagalan dan pelajaran
Kegagalan nyata yang dialami adalah ketidakcocokan dependensi *wheel* `duckdb` pada lingkungan Python 3.13 di Windows yang sempat menghentikan proses *build* virtual environment (`.venv`) dan eksekusi `pip install -r requirements.txt`. Pelajaran yang diambil adalah perlunya memasang pustaka dalam bentuk *binary wheel* yang tepat via `pip install duckdb --only-binary=:all:` serta memperbarui `pip` sebelum menginstal pustaka dependen lainnya agar skrip *pipeline* dapat berjalan tanpa hambatan eksekusi.
